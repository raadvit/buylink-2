## Why / Business Goal
Pokud uživatel zadá špatnou URL zobrazí se 404 stránka

## Co se zobrazuje
V horní liště je logo alzaBox vlevo. Vpravo jsou tři odkazy: Jak to funguje, Obchodní podmínky, a rozbalovací menu Můj účet. Vedle menu je zelené tlačítko Nový inzerát.

Uprostřed obrazovky je velká zelená ikona s robotem a lupou. Pod ikonou je tučný nadpis Stránka nenalezena a menší text Tato stránka neexistuje.

Dole je tmavě modré tlačítko Přejít na hlavní stránku se šipkou směřující doprava.

## Acceptance Criteria

1. KDYŽ uživatel navštíví neexistující URL, PAK se vykreslí 404 stránka se správným HTTP statusem 404
2. KDYŽ je stránka zobrazena, PAK header obsahuje: alzaBox logo vlevo, odkazy (Jak to funguje, Obchodní podmínky), menu Můj účet a tlačítko Nový inzerát
3. KDYŽ je stránka zobrazena, PAK střed obsahuje: ikona robota s lupou, nadpis "Stránka nenalezena" (bold), text "Tato stránka neexistuje."
4. KDYŽ uživatel klikne na tlačítko "Přejít na hlavní stránku", PAK se přesměruje na /
5. KDYŽ je viewport mobilní (<768px), PAK se stránka zobrazí responzivně bez horizontálního scrollování

## Architecture Notes

- Next.js App Router zachytává neznámé cesty automaticky souborem `app/not-found.tsx`. Vrací HTTP 404 nativně.
- Existující `<Header />` komponenta se importuje přímo; stránka nemá vlastní navigaci.
- Mascot obrázek je statický asset v `public/images/mascot-404.png`, servován přes `next/image`.
- Tlačítko je `<Link href="/">` z `next/link` — client-side přechod.
- Tailwind CSS 4.x: centrování přes `flex flex-col items-center justify-center min-h-screen`.
- Soubor `app/not-found.tsx` na kořenové úrovni pokrývá všechny cesty.

## Implementation Plan

**Frontend:**

1. Přidat mascot obrázek do `public/images/mascot-404.png`
2. Vytvořit `app/not-found.tsx` — Server Component, importovat `<Header />`, `next/image`, `next/link`
3. Layout: `<Header />` nahoře, šedé pozadí, centrová sekce s mascot obrázkem (kulatý fialový kruh), `<h1>` Stránka nenalezena (bold), `<p>` Tato stránka neexistuje., `<Link href="/">` tmavě modré tlačítko se šipkou
4. Responsivita: oobrázek `w-32 h-32 md:w-48 md:h-48`, žádný horizontální overflow
5. HTTP 404 vrací `not-found.tsx` automaticky

**Dotčené soubory:**
- `public/images/mascot-404.png` — nový asset
- `app/not-found.tsx` — nový soubor

## Manuální QA scénář

**Prerekvizita:** aplikace běží lokálně (`yarn dev`, port 3000).

1. Přejít na `http://localhost:3000/neexistujici-stranka` — očekáváno: stránka se zobrazí, DevTools Network status 404
2. Zkontrolovat header — alzaBox logo, Jak to funguje, Obchodní podmínky, Můj účet, zelené + Nový inzerát
3. Zkontrolovat střed — mascot robot s lupou, tučný nadpis Stránka nenalezena, text Tato stránka neexistuje.
4. Kliknout na Přejít na hlavní stránku — očekáváno: URL → `/`, hlavní stránka
5. Navštívit `http://localhost:3000/a/b/c/d` — 404 stránka se zobrazí
6. Zúžit okno na 375 px — žádný horizontální scrollbar
