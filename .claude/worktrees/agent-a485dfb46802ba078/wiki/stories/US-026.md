## Technické poznámky (Architekt)
Widget kurz EUR je UI komponenta v task-forge aplikaci (administrativní rozhraní pro tvorbu user stories), nikoli součást business domény Zlatničku. Skládá se z:

**Frontend:**
- HTML: element `<span id="eur-value">` v containeru `.eur-box` (static/index.html:193-196)
- CSS: stylování `.eur-box`, `.eur-label`, `.eur-value`, `.eur-error` (static/style.css:177-180)
- JavaScript: funkce `loadEurRate()` volající `/api/eur-rate` a renderující kurz na element (static/app.js:853-870)
- Event: funkce se volá při `DOMContentLoaded`

**Backend:**
- Flask endpoint: `GET /api/eur-rate` (task-forge.py:519-533)
- Fetchuje XML z https://www.cnb.cz/ (ČNB kurzy)
- Parsuje EUR kurz a vrací JSON `{rate: number}`
- Error handling: vrací 502 при neúspěchu

**Závislosti:**
- Žádné. Widget je izolovaný, bez vazby na jiné components.
- Vlastní kurz nedělá nic - je to čistě informativní zobrazení

1. Smazat HTML element a kontejner z index.html

3. Smazat JS funkci `loadEurRate()` a event listener
4. Smazat Flask endpoint `/api/eur-rate` a import urllib/ET (pokud nejsou použity jinde)
